# 使用 MineEcho 技能

## 何时使用此技能

- 用户问"你能做什么"
- 用户问"有什么技能/功能"
- 用户有一个需求但不知道如何完成
- 用户问"怎么用技能系统"

## 技能发现原则

1. **主动匹配**：如果用户的问题可能由某个技能解决，必须主动告知该技能
2. **技能列表**：所有已加载技能都在 ${SKILL_ROOT} 目录下
3. **优先级**：
   - 直接匹配 > 相关匹配 > 建议技能
   - 如果有 1% 的概率某个技能适用，必须提及它

## 使用流程

1. 理解用户需求
2. 分析可用技能（检查已加载技能列表）
3. 匹配最合适的技能
4. 如果完全匹配：建议使用该技能
5. 如果没有完全匹配：推荐相关技能或解释如何创建新技能
